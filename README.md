# منصة إدارة مجموعات ومجتمعات واتساب 🚀
**WhatsApp Groups & Communities Control Center**

منصة متكاملة وسريعة مبنية بلغة **JavaScript / Node.js** ومحرك **Baileys** لإدارة مجموعات ومجتمعات واتساب بكفاءة عالية، مع واجهة مستخدم عربية عصرية (RTL) ولوحة تحكم تفاعلية لحظية.

---

## 🌟 المزايا المنجزة

### 1. استعراض وتصفية المجموعات والمجتمعات
* **جلب تلقائي لكافة المجموعات** التي أنت عضو أو مشرف فيها مع تفاصيل دقيقة:
  * عدد الأعضاء الحاليين.
  * رتبتك في المجموعة (مالك / مشرف ⭐ / عضو).
  * تمييز المجتمعات (Communities) ومجموعات الإعلانات.
  * تاريخ إنشاء المجموعة وحالة الإرسال (مفتوح للجميع أو مقفل للمشرفين فقط).
* **تصفية وبحث ذكي ولحظي**:
  * بحث بالاسم أو معرف المجموعة (JID).
  * فلاتر سريعة: (الكل / المجموعات التي أنت مشرف فيها / أنت عضو / المجتمعات).
* **إحصائيات رقمية مباشرة (KPIs)**:
  * إجمالي المجموعات.
  * المجموعات الخاضعة لإشرافك.
  * المجتمعات التابعة لك.
  * الوصول الإجمالي (مجموع عدد الأعضاء عبر كل المجموعات).

### 2. إدارة الأعضاء المتقدمة
* **قائمة الأعضاء التفاعلية**:
  * عرض جميع أعضاء أي مجموعة مع أرقام هواتفهم ورتبهم.
  * بحث وتصفية داخل أعضاء المجموعة برقم الهاتف.
* **إجراءات المشرفين (Admin Actions)**:
  * **إضافة عضو جديد**: إدخال رقم الهاتف وإضافته للمجموعة مباشرة.
  * **طرد عضو (Remove / Kick)** مع رسالة تأكيد لحماية المجموعة من الحسابات المزعجة.
  * **ترقية عضو لمشرف (Promote)**.
  * **خفض رتبة المشرف إلى عضو (Demote)**.
* **تصدير جهات الاتصال (Export Members)**:
  * تصدير فوري لقائمة أرقام أعضاء المجموعة بملف **CSV (Excel)** متوافق مع اللغة العربية بضغطة زر واحدة.

### 3. إعدادات وتحكم فوري بالمجموعة
* **قفل الإرسال / فتحه (Announcement Mode)**: تحويل المجموعة بنقرة زر إلى وضع الإعلانات فقط (المشرفين فقط) أو السماح للجميع بالمشاركة.
* **استخراج رابط الدعوة (Invite Link)**: سحب رابط الانضمام للمجموعة ونسخه بنقرة واحدة.
* **إرسال رسائل أو إعلانات**: كتابة إعلان وإرساله فوراً لأي مجموعة من اللوحة.

## 🚀 طريقة التشغيل

### المتطلبات:
* تثبيت **Node.js** (الإصدار 18 فما فوق).

### خطوات البدء:
```bash
# 1. تثبيت الحزم (تم تثبيتها مسبقاً)
npm install

# 2. تشغيل السيرفر
npm start
```

بعد التشغيل، افتح المتصفح على:
👉 **`http://localhost:3000`**

---

## 📱 طريقة الربط بواتساب:
1. افتح الرابط في المتصفح وستظهر لك شاشة بها رمز الاستجابة السريعة (**QR Code**).
2. افتح تطبيق **واتساب** في جوالك 👈 الإعدادات (أو القائمة الثلاثية) 👈 **الأجهزة المرتبطة (Linked Devices)**.
3. اضغط **ربط جهاز** وامسح الرمز المعروض على الشاشة.
4. بمجرد المسح، سيتم حفظ الجلسة محلياً في مجلد `auth_info_baileys`، وستظهر مجموعاتك ومجتمعاتك فوراً!

## 🔌 واجهة الـ REST API

| الطريقة | المسار (Endpoint) | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/status` | فحص حالة الاتصال ومعلومات الحساب المتصل |
| `GET` | `/api/groups` | جلب قائمة كافة المجموعات والمجتمعات مع الإحصائيات |
| `GET` | `/api/groups/:jid` | جلب تفاصيل مجموعة محددة مع كامل قائمة الأعضاء |
| `POST` | `/api/groups/:jid/participants` | إضافة / طرد / ترقية / خفض رتبة عضو (`add`, `remove`, `promote`, `demote`) |
| `POST` | `/api/groups/:jid/setting` | تعديل إعداد قفل الإرسال (`announce`) |
| `GET` | `/api/groups/:jid/invite` | استخراج رابط دعوة المجموعة |
| `POST` | `/api/groups/:jid/send` | إرسال رسالة نصية للمجموعة |
| `GET` | `/api/groups/:jid/export-csv` | تحميل ملف CSV يحتوي على أرقام ورتب الأعضاء |
| `POST` | `/api/logout` | تسجيل الخروج ومسح الجلسة للربط برقم آخر |
